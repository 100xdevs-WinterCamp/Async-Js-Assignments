# JavaScript & Asynchronous JS Assignments

A structured collection of JavaScript exercises to build and solidify your problem-solving and async programming skills.

## Recommended Solving Order

Solve the assignments in the following sequence:

1. **[js-basics](./js-basics/)** – Core syntax, arrays, objects, and foundational concepts.
2. **[js-built-ins](./js-built-ins/)** – Common JavaScript built-in methods and utilities.
3. **[01-js](./01-js/)** – Logic building and algorithmic problem solving (Easy, Medium, Hard).
4. **[01-async-js](./01-async-js/)** – Introduction to asynchronous JavaScript, timers, and file system tasks.
5. **[advanced-js](./advanced-js/)** – Deep dive into callbacks, promises, and CPU/IO-bound operations.

> ** Note on `advanced-js`:**  
> If you find the **medium** or **hard** problems in `advanced-js` very difficult, feel free to skip them for now. Move forward and revisit them after a few days with fresh eyes!

---

##  Getting Started

1. Navigate into any assignment directory:
   ```bash
   cd <folder-name>
   ```
2. Install dependencies (where applicable):
   ```bash
   npm install
   ```
3. Check the respective folder's `README.md` for specific test commands and instructions.
